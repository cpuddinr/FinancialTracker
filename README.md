Semua data disimpan di local storagee browser, agar data tetep ada walaupun page di refresh atau close.

Flow websitenya dimulai dari memilih kategori yang tersedia atau menambah kategori baru kemudian meng-input nominal dan juga catatan. kemudian bisa save transaksi agar dapat dicatat pada bagian history.
(ex: kategori makanan, nominal 15000 dengan catatan makan siang)
